# README screenshot

`demo-model-performance.jpg` is an unaltered 1600 × 1100 desktop capture from the public
WildEdge demo on 2026-10-21. It shows sample data, not measurements from the
Python quickstart.

To refresh: open https://wildedge.dev/demo, switch to News Reader, then open
Models → Article Summarizer. Use a 1600 × 1100 viewport so the sidebar fits without a scrollbar. Capture
the full viewport, including the model heading, health notice, performance
cards, and charts. Keep metric values as displayed; do not fabricate data.

The README links to the demo entry point because direct navigation to nested
model routes currently loads the marketing page.
